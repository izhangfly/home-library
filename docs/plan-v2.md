# v2 计划：中图法 + 自动布局 + 3D 空间

## 0. 最难的那个约束，先说清楚

用户原话（大意）：**你不知道我一开始有多少书、有哪些书，我也不可能把所有书抽出来重新摆一遍，
只能一个书架一个书架地弄。**

这一句把算法的形态定死了：

- **不能做全局最优批处理。** 那需要"清空→重排"，物理上不可行。
- **必须是在线（online）算法**：书一本一本进来，每次只做局部决策。
- **重排必须是局部的、罕见的、可拒绝的。**

这正好落在 `docs/shelving-design.md` 里查到的 list labeling 问题上：
有序序列里插入元素、让搬动次数最少。学界四十年的结论是——
**别把空隙留在末尾，要均匀撒开**；配合图书馆书库 70–75% 装填率的经验值，
新书插入基本只在本层内挪动，不会引发跨层雪崩。

所以整套流程是：

```
盘点模式（一次一个书架，扫完这架的书）
 ↓ 系统知道了这架现在有什么
增量上架（每扫一本新书 → 就近插入，尽量不动别人）
 ↓ 只有真的塞不下 / 某类彻底放不下了
迁移建议（挑最小的那一组挪，先预览再执行，可撤销）
```

## 1. 分类：换成中图法

DDC 把中文文学全压进 895.1x，对一个以中文书为主的家庭书房等于没分类。
中图法 I2 下有上百个细目，正好落在藏书最厚的那一段。

- 主号：中图法（`clc`），索书号 = 中图法号 + 著者号
- 旧的 `ddc` 字段**保留不删**，详情页仍展示（OpenLibrary 的权威号是真数据，扔了可惜）
- 中图法没有免费权威源 → 规则 + DeepSeek（中文模型，对中图法熟）

## 2. 主题接近度（topic closeness）

"哪些类该挨着放"不能拍脑袋。中图法本身就是层级编码，
**共同前缀越长 = 学科越近**，这是现成的距离度量：

```
closeness(I247.5, I247.7) = 共同前缀 "I247." → 很近
closeness(I247.5, I226) = 共同前缀 "I2" → 同为中国文学，中等
closeness(I247.5, TP311) = 共同前缀 "" → 毫无关系
```

再叠加物理距离矩阵（书柜坐标来自户型图，单位毫米），
目标函数就是：**让学科距离近的书，物理距离也近**。

## 3. 房间

- 户型图里的闭合多段线 = 房间轮廓，导入时自动切出候选房间
- 每个房间可命名、给淡色
- 检索结果给出完整路径：`房间 › 书柜 › 分区 › 层 › 索书号 › 类目`

## 4. 3D

| 需求 | 做法 |
|---|---|
| 默认 45° 墙角视角 | 方位角 45°、俯仰 35°，从包围盒对角起手 |
| 墙 = 地面射灯向上打、无限淡出 | 竖直渐变，底部不透明→顶部全透明，不封顶 |
| 鼠标/手指旋转整屋 | 指针拖拽改方位角与俯仰 |
| 悬停高亮房间 | 房间多边形做拾取区，悬停变色 |
| 房间半透明、能看穿到书架 | 房间体块低透明度填充 |
| 书架按真实尺寸生成网格 | 柜体 + 层板 + 分区隔板，全部来自实测毫米 |
| 网格上带类目标签 | 每层正面贴该层主类目的中图法号与名称 |
| 点进房间 → 相机入内 | 切内视模式：实墙、相机移到房间中心 |
| 左右按钮切书架 | 相机平移+旋转到正对该柜正面 |
| WASD 平移 | 键盘监听，改相机目标点 |

技术选型：继续用**投影到 SVG**，不引 three.js。
理由：全是轴对齐盒子和竖直面，用不到材质光照；SVG 能选中、能贴文字、
矢量在手机上也清晰，而且天然继承网站的粗描边风格。
"地灯打上去"的效果用 SVG 线性渐变就能做，比在 three.js 里配 shader 简单得多。

## 5. 我主动加的（用户没提，但我认为这个应用需要）

1. **盘点模式（最重要）** —— 直接解决"冷启动"问题：
 选一个书架 → 连续扫这架上的书 → 系统就知道这架现在有什么。
 不用一次盘完全屋，随时可以只盘一格。
2. **错架检测** —— 盘点时扫到一本"系统认为在别处"的书，说明它被挪过了，
 自动更正位置，不用手工记账。
3. **理架清单** —— 待搬动的书列成一张清单，按"少走路"的顺序排，
 拿着手机照着做，做完打勾。
4. **批量移动可撤销** —— 迁移一次动几十本，必须能一键回退。
5. **书脊标签打印** —— 既然要做成真图书馆，就该能打印索书号贴纸。
6. **容量预测** —— "按最近的加书速度，客厅大书柜约 4 个月后满"。
7. **3D 不能是唯一入口** —— 3D 好看，但找书必须有纯列表路径可走
 （无障碍要求，也为了手机上快）。

## 6. 顺序

1. 中图法落地（分类是一切的基础）
2. 房间模型 + 命名
3. 增量放置算法 + 主题接近度
4. 3D 重做（外视 → 内视）
5. 检索目录路径、扫码流程改造、盘点模式
